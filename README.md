# Süleyman Poyraz

**Software engineer: Linux, embedded systems and networking.** I work mostly in C, C++ and Rust, and I like the details: what goes over the wire, where a process spends its time, and how a parser handles the input it gets.

My open-source work runs from Linux package management to network analysis and protocol libraries. I also write about these topics in Turkish.

### Systems & networking

| Project | Stack | Summary |
| --- | --- | --- |
| [**imshark**](https://github.com/Zaryob/imshark) | `C++20` `Dear ImGui` | Packet analyzer for live traffic and saved captures. Covers TCP/IP reassembly, stream inspection, display filters and TLS decryption with session keys. The UI links each decoded field to its packet bytes. |
| [**docker-tui**](https://github.com/Zaryob/docker-tui) | `Go` `Docker Engine API` | Terminal UI for Docker with Compose controls, combined logs, live resource stats, image builds and an embedded container shell. Daemon events keep the views up to date. |
| [**abitur**](https://github.com/Zaryob/abitur) | `Elf Parser` | Structural ABI comparison for ELF libraries, with command-line and Dear ImGui interfaces. |
| [**Performer**](https://github.com/Zaryob/Performer) | `C++` `Dear ImGui` | Performer measures CPU use, waiting, and lock contention in Linux processes. It writes a portable .tgz bundle; the offline viewer opens bundles in the browser and compares two runs. |
