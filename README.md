## Systems & Tooling

| Project | Stack | What to explore |
| --- | --- | --- |
| [imshark](https://github.com/Zaryob/imshark) | `C++20` `Dear ImGui` `libpcap` | Packet analysis, capture readers, protocol dissection and a Dear ImGui desktop interface. Start with the support matrix and validation record. |
| [Performer](https://github.com/Zaryob/Performer) | `eBPF` `Linux` `Tracing` | Linux process profiling with eBPF, portable measurement bundles and an offline viewer. Synthetic demos are available separately from live measurements. |
| [docker-tui](https://github.com/Zaryob/docker-tui) | `Go` `Docker API` `TUI` | Fast, keyboard-driven terminal user interface for Docker without SDK overhead, talking directly to the Docker daemon. |
| [tapir](https://github.com/Zaryob/tapir) | `Homebrew` | Shared Homebrew tap for Zaryob macOS and Linux utilities (`brew tap Zaryob/tapir`). |
