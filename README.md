# Süleyman Poyraz · Zaryob

I build systems software, developer tools and native applications, with a focus on Linux, networking, performance and parsers.

## Systems & Tooling

| Project | What to explore |
| --- | --- |
| [imshark](https://github.com/Zaryob/imshark) | C++ packet analysis, capture readers, protocol dissection and a Dear ImGui desktop interface. Start with the support matrix and validation record. |
| [Performer](https://github.com/Zaryob/Performer) | Linux process profiling with eBPF, portable measurement bundles and an offline viewer. Synthetic demos are available separately from live measurements. |

## Applications

| Project | What to explore |

## Libraries & Research

| Project | What to explore |
| --- | --- |
| [iksemel-rs](https://github.com/Zaryob/iksemel-rs) | Rust XML/XMPP implementation inspired by Gürer Özen's iksemel; parser limits, protocol helpers and benchmark tooling. |
| [iksemel](https://github.com/Zaryob/iksemel) | Downstream of [Gürer Özen's C library](https://github.com/meduketto/iksemel), with Meson build work. Read its security limitations before using the networking backends. |
